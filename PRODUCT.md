# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
JOY visitors and players discovering events, comparing pricing and membership,
then opening an existing public tournament detail and registration flow.

## Product Purpose
Provide public club information and event discovery without exposing management.

## Capabilities and Constraints
User approved an Events entry beside Pricing and Membership, venue and event-kind
filters, live and near-term events first, local venue time and explicit currency.
This iteration is local preview only. Preserve all existing registration, account,
payment and management behavior; no production deployment or database mutations.

## Brand Commitments
Keep the existing JOY website style and bilingual Chinese/English experience.
PublicClubHeader, PublicClubFooter and PricingPage are incumbent visual evidence.

## Product Principles
Use real public event data, never fabricate availability, prices or registrations.
Unavailable data is an error or unknown value, not a false zero or success.
Existing event links remain the sole next step into registration.
